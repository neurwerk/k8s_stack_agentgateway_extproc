# Security Policy

## Supported Versions

Security fixes are developed on `main` and released in the newest tagged
version. Older releases are not supported unless maintainers state otherwise.

| Version | Supported |
| --- | --- |
| Latest release | Yes |
| `main` | Development fixes |
| Older releases | No |

## Reporting a Vulnerability

Use [GitHub private vulnerability reporting](https://github.com/neurwerk/k8s_stack_agentgateway_extproc/security/advisories/new).
Do not open a public issue for a suspected vulnerability.

Include the affected version, impact, reproduction steps, and a minimal
synthetic test case. Never include credentials, private keys, certificates,
unredacted personal data, or production request and response bodies.

Maintainers will coordinate validation, remediation, release timing, and
disclosure through the private advisory. Please allow time for a fix before
publishing details.
